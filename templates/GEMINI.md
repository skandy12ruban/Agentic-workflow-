## Gemini CLI specifics
- Custom commands live in `.gemini/commands/*.toml` (generated by `scripts/install.sh --tool gemini`).
- When a command says "delegate to the `X` agent" and native subagents aren't enabled in your version, read `.agentic/agents/X.md` and perform that role yourself as a focused sub-task.
- When a command says "apply the `Y` skill", read `.agentic/skills/Y/SKILL.md` (or use native skills if enabled).
- Use `/memory show` to confirm this file and AGENTS.md are loaded.
